# 내 주변의 공공 화장실 Catch Toilet
![logo](https://github.com/busanit2024/android-project/blob/dev/catchToiletLogo.png)

오픈API를 활용하여 내 주변의 공공 화장실 위치를 알려주는 Android App을 Android Studio와 Kotlin 을 활용하여 제작하여 구현하였습니다.

## 프로젝트 소개
Catch Toilet은
> **편의성** : 누구나 쉽게 접근 가능한 공공 편의시설 정보 제공을 목표로, 깔끔하고 직관적인 디자인과 편리한 기능을 갖추고 있습니다.
> 
> **실시간 정보 제공** : 사용자의 위치와 연동된 실시간 정보 업데이트로 정확하고 빠른 위치 안내가 가능합니다.
> 
> **사용자 참여 기반의 데이터 신뢰도 향상** : 공공 화장실의 실제 이용 상황을 사용자가 리뷰, 정보 수정을 통해 직접 반영하여 사용자들이 신뢰할 수 있는 정보를 제공합니다.

## 🧩주요 기능
### ✔️ 화장실 정보 지도에 표시하기
- 구글 지도 API 활용, 공공데이터 활용. 공공 화장실의위치를 지도에 표시
- 선택한 위치에 마커를 띄워서 상세정보 페이지로 이동.
- 기존 위치 검색 및 신규 위치 등록 가능.
- 편의시설_남여공용, 장애인용, 기저귀교환대 유무 표시
### ✔️ 화장실 상세 정보
- 사용자가 선택한 화장실 정보를 표시하며 개방 시간, 기저귀 교환대 등의 편의시설 유무 등 옵션 사항을 표시.
- 로그인 회원은 즐겨찾기 기능을 통해 즐겨찾는 화장실로 등록 가능.
### ✔️ 화장실 상세 정보 수정 
- 사용자가 사용 후 직접 화장실 정보 수정. 로그인 회원은 관리자에게 삭제요청 가능.
### ✔️ 리뷰 
- 사용 경험과 휴지 여부, 청결도, 칸 개수를 toggle chip 방식으로 간편히 등록 할 수 있음.

### ✔️ 관리자

### ✔️ 마이페이지 
- 회원정보(프로필 이미지, 닉네임 등)를 불러오며, 회원정보 수정과 회원탈퇴 버튼을 표시.
  로그아웃된 상태일 때는 버튼 ui 변경
- 회원정보를 수정할 때, 소셜로 로그인했을 경우에는 닉네임만 수정할 수 있음.
  기본적으로 비밀번호와 닉네임 수정 가능.
- 회원탈퇴를 할 때 한 번 더 확인을 받은 후, 회원탈퇴를 함.
- 관리자로 로그인하면 관리자 페이지 버튼이 따로 드러남.
  (일반 유저에게는 보이지 않음)
- 북마크(즐겨찾기)와 나의 리뷰를 볼 수 있음.
  (북마크는 여기서 바로 끌 수 있음)
